# 状態ストア

バックエンドが、木とやりとりのほかに持つ状態を、どこに置くかを確かめるときに読む。
アダプタは [アダプタ](../../adapters/README.md) に書く。

## 置くもの

| 状態 | 内容 |
|---|---|
| イベントのログ | repository ごとの変化の記録と、その番号（seq） |
| Idempotency-Key | 同じ要求の繰り返しを見分けるための、キーと最初の応答 |
| 主体とトークン | API を使う主体と、そのトークン |
| repository の登録 | repository の名前と、プロバイダ側の参照（provider_ref） |
| 突き合わせの状態 | repository ごとの、最後に反映したリビジョンと、最後に突き合わせた時刻 |

- イベントのログは、行を加えるだけにする。
- イベントのログは、API の [イベントの一覧](../../api/endpoints/event/list.md) で読み出す。
- 主体とトークンの決まりは、[認可](../README.md) に書く。

## 置かないもの

- 木（[木のリポジトリ](tree-repository.md) に置く）
- 提案、レビュー、人への依頼（[やりとり](interaction.md) に置く）
- artifact の中身（[CAS](cas.md) に置く）
- 秘密情報（[アダプタ](../../adapters/README.md) の「設定と秘密情報」）
