# サーバの状態

バックエンドが、木とやりとりのほかに持つ状態を、どこに置くかを確かめるときに読む。
アダプタは [アダプタ](../../adapters/README.md) に書く。

## 置くもの

| 状態 | 正本かキャッシュか | 作り直す元 |
|---|---|---|
| 主体とトークン | 正本 | なし |
| repository の登録（名前と provider_ref） | キャッシュ | 木の読み書きの「列挙する」と、サーバの設定 |
| イベントのログ | キャッシュ | `main` のコミットの trailer と、やりとりのデータ |
| Idempotency-Key | キャッシュ | なし（失ってよい） |
| 突き合わせの状態 | キャッシュ | `main` のコミットの trailer |

- サーバの状態で正本なのは、主体とトークンだけである。ほかはすべて作り直せる。
- バックアップを取るのは、主体とトークンだけでよい。
- イベントのログは、行を加えるだけにする。

## 失ったときの影響

| 失ったもの | 影響 |
|---|---|
| 主体とトークン | 誰も API を使えなくなる。バックアップから戻す |
| repository の登録 | 起動時に、木の読み書きの列挙とサーバの設定から作り直す |
| イベントのログ | 作り直すまでの間、イベントの一覧は `cursor_expired` を返す。外の仕組みは最初から読み直す |
| Idempotency-Key | 失う前に送った要求を送り直すと、二重に処理されることがある |
| 突き合わせの状態 | 次の突き合わせで、`main` から作り直す |

## 置かないもの

- 木（[木の読み書き](tree-read-write.md) に置く）
- 提案、レビュー、人への依頼（[やりとり](interaction.md) に置く）
- artifact の中身（[ファイルの保管](file-storage.md) に置く）
- 秘密情報（[アダプタ](../../adapters/README.md) の「設定と秘密情報」）

主体とトークンの決まりは、[認可](../README.md) に書く。
