# サーバの状態

バックエンドが、木とやりとりのほかに持つ状態と、その作り直し方を確かめるときに読む。
構成ごとのアダプタと、失ったときの影響は、[組み合わせ](../../adapters/README.md) に書く。

## 置くもの

| 状態 | 作り直す元 |
|---|---|
| repository の登録（名前と provider_ref） | 木の読み書きの「列挙する」と、サーバの設定 |
| Idempotency-Key | なし（失ってよい） |
| 突き合わせの状態 | `main` のコミットの trailer |

- サーバの状態は、すべて作り直せるキャッシュである。
