# サーバの状態

バックエンドが、木とやりとりのほかに持つ状態を、どこに置くかを確かめるときに読む。
アダプタは [アダプタ](../../adapters/README.md) に書く。

## 置くもの

| 状態 | 作り直す元 |
|---|---|
| repository の登録（名前と provider_ref） | 木の読み書きの「列挙する」と、サーバの設定 |
| イベントのログ | `main` のコミットの trailer と、やりとりのデータ |
| Idempotency-Key | なし（失ってよい） |
| 突き合わせの状態 | `main` のコミットの trailer |

- サーバの状態は、どの構成でも、すべて作り直せるキャッシュである。
- イベントのログは、行を加えるだけにする。

## 構成ごとの正本

主体とトークンは、このポートではなく [認証](authentication.md) のポートが扱う。
同じ SQLite ファイルに置く、ほかのポートのテーブルも含めて、構成ごとの正本は次のとおりである。

| 構成 | SQLite ファイルの中の正本 | バックアップ |
|---|---|---|
| GitHub を使う構成 | なし（すべてキャッシュ） | 要らない |
| GitHub を使わない構成 | 認証の主体とトークン、独自プロバイダのテーブル | SQLite ファイルを取る |

## 失ったときの影響

| 失ったもの | GitHub を使う構成 | GitHub を使わない構成 |
|---|---|---|
| repository の登録 | 起動時に作り直す | 起動時に作り直す |
| イベントのログ | 作り直すまで `cursor_expired` を返す | 作り直すまで `cursor_expired` を返す |
| Idempotency-Key | 前に送った要求を送り直すと、二重に処理されることがある | 同じ |
| 突き合わせの状態 | 次の突き合わせで作り直す | 同じ |
| 主体とトークン | 影響なし（GitHub が正本） | 誰も API を使えなくなる。バックアップから戻す |

## 置かないもの

- 木（[木の読み書き](tree-read-write.md) に置く）
- 提案、レビュー、人への依頼（[やりとり](interaction.md) に置く）
- artifact の中身（[木の読み書き](tree-read-write.md) の git リポジトリに置く）
- 主体とトークン（[認証](authentication.md) に置く）
- 秘密情報（[アダプタ](../../adapters/README.md) の「設定と秘密情報」）
