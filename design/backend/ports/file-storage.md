# ファイルの保管

バックエンドが、artifact の中身を置くときに使うポートを確かめるために読む。
中身は、ハッシュで番地を決めて置く（内容アドレス方式）。

## 操作

| 操作 | 内容 |
|---|---|
| 置く | 中身を受け取り、SHA-256（ハッシュ関数の 1 つ）を返す |
| 読む | SHA-256 で中身を読む |
| あるか確かめる | SHA-256 の中身があるかを返す |

- 同じ SHA-256 に、別の中身を置かない。
- 反映の前のアップロード（blob、artifact、回答の添付）は、すべてこのポートに置く。
  - なぜ：中身で番地が決まるので、反映されなくても害がないから。
- 反映のとき、小さい artifact だけを、[木の読み書き](tree-read-write.md) にも入れる（[artifact の置き方](../../files/artifacts.md)）。
