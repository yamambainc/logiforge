# スナップショットの置き場

バックエンドが、[スナップショット](../snapshot.md) を読むときと、[worker](../worker.md) に取り込みを頼むときに使うポートを確かめるために読む。

## 置いてあるもの

| キー | 中身 | 変わるか |
|---|---|---|
| `v<版>/<repository>/commits/<SHA>` | スナップショットのコミットの記録。`main` のすべてのコミットと、ブランチの先頭にある | 変わらない |
| `v<版>/<repository>/snapshots/<SHA>` | スナップショットの木（`main`）か差分（ブランチ）。`main` の木は、決まったコミットにだけある（[木を作るコミット](../snapshot.md#木を作るコミット)） | 変わらない |
| `v<版>/<repository>/latest` | 今の `main` の SHA（[latest](../snapshot.md)） | 変わる |
| `v<版>/repositories` | `latest` がある repository の名前の一覧 | 変わる |
| `keep/<repository>/artifacts/<sha256>` | artifact のファイルの中身 | 変わらない |
| `keep/<repository>/branches/<ブランチの名前>` | ブランチの履歴（[ブランチの履歴](../snapshot.md)）。ブランチの名前は、パスとしてエスケープする（`/` を `%2F` に） | 変わる |
| `keep/<repository>/branch-index` | 履歴のあるブランチの名前の一覧。消えたブランチを見つけるのに使う | 変わる |

- git から作り直せるものは、形の版の接頭辞（`v<版>/`）の下に置く。
  - 形の版（`format_version`）が変わったら、新しい版の worker は、空の接頭辞から作り直す。古い版は、消さずに残す。
  - なぜ：形の違うスナップショットを、同じキーで混ぜないため。作り直せるので、移す必要がない。
- 作り直せないもの（ブランチの履歴と、その一覧）と、形を持たないもの（artifact の中身）は、版の外の `keep/` に置く。
  - ブランチの履歴は、git から作り直せないので、バックアップを取る。形を変えるときは、読めるように移す。
- 置き場の直下には、`v<版>/` と `keep/` だけを置く。なぜ：repository の名前（`v4` など）と、ぶつからないようにするため。
- `main` のコミットの記録があっても、木があるとは限らない。ブランチの先頭は、差分を先に置き、コミットの記録をあとに置く。コミットの記録があれば、差分もある。
- `latest` が指すコミットには、いつも木がある。worker は、木を置いてから `latest` を書く。
- `latest`、ブランチの履歴、ブランチの名前の一覧は、条件付きで書く（読んだときの値のときだけ書く）。静的ファイルストレージでは、ETag と `If-Match`（ないときは `If-None-Match: *`）で書く。
- ブランチの名前をエスケープするのは、`a` と `a/b` が、ファイルとディレクトリでぶつからないようにするため。

## 操作

| 種類 | 操作 | 内容 |
|---|---|---|
| 置き場を読む | 読む | キーの中身を返す。なければ、ないことを返す |
| worker に頼む | ブランチを読む | worker に、ブランチの先頭と base を求め、差分のスナップショットを作ってもらう。apply request を作るときに使う |
| worker に頼む | 木を作る | worker に、`main` のコミットの木を作ってもらう。過去のリビジョンを読むときに、その木がなければ使う |
| worker に頼む | 起こす | GitForge に書いたあとに、worker に巡回を始めてもらう |

- 「worker に頼む」操作も、このポートに置く。どちらも、置き場に読む側のものを作ってもらうためのものだからである。
- アダプタは、置き場を読む部分と、[worker の内部 API](../worker-api.md) のクライアントからなる。
- バックエンドは、置き場を読むだけである。
- 書くのは [worker](../worker.md) だけで、worker の中の別のインターフェースで書く。このポートには、書く操作を置かない。
  - なぜ：バックエンドが置き場に書かないことを、ポートの形で守るため。

アダプタは、[スナップショットの置き場のアダプタ](../../adapters/snapshot-store.md) に書く。
