# 人への依頼の起票と回答

バックエンドが、人への依頼の起票と回答で、何をどうするかを確かめるときに読む。
要件は [人への依頼](../../docs/human-requests/README.md) が正本である。

## 起票

- 人への依頼の起票は、起票する主体のトークンで GitForge に issue を作り、応答する。git には書かない（[人への依頼の issue](../adapters/texts.md#人への依頼の-issue)）。
  - 依頼の識別子は、issue の番号である。
  - 送り直しの扱いは、[同じ要求の繰り返し](../api/writes.md) に書く。
- 対象は、今の `main` のスナップショットツリーの、active な仮説で、葉か要再検討であるものに限る。違えば `validation_failed` にする。

## 回答

1. 回答した利用者のトークンで、回答の本文と添付を issue のコメントに書き、同じトークンで issue を close する（[回答](../adapters/texts.md#回答)、[人への依頼の回答](../files/artifacts.md)）。
   - issue がすでに closed で、回答の本文と回答した利用者が同じなら、送り直しとみなして成功とする。違えば `not_open` で受け付けない。
   - コメントを書いたあと、close の前に止まったら、送り直しで、同じ本文のコメントを書き直さずに close する。
2. 応答する。

- 回答は、git に書かない。
