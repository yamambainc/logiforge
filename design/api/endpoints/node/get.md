# ノードの詳細を読む

利用者が木のビューアでノードを選んだとき、opener や reviewer がノードの根拠を確かめるときに呼ぶ。

## 呼び出し

- `GET /nodes/{nodeId}`
- operationId：`getNode`

## すること

- 仮説かストーリーの内容と、値・状態を返す。
- 子ノードを返す。
- 有効な検証結果と、そのレポート・artifact・引用を返す。
- このノードの部分木を引用している検証結果を返す。
- リビジョンを指定すると、その時点の内容を返す。

## 失敗する主な場合

- `not_found`

エラーの形は、[エラー](../../README.md) に書く。
