# 木のファイル配置

木（仮説、ストーリー、検証結果、背景情報、inactive 化）を、git リポジトリのどのファイルに置くかを確かめるときに読む。
木は、どのプロバイダを使っても、このファイル配置で git リポジトリに置く（[レイヤー構成](../architecture.md)）。
1 つの project（[木の形](../../docs/tree/README.md)）が、1 つの git リポジトリにあたる。

## 考え方

- 木の状態は、リポジトリの `main` ブランチにファイルとして置く。
- 変更は、ブランチの差分として出す。
  - 差分が [apply request](../../docs/apply-request/README.md) にあたる。
- 値（真偽）は、ファイルに保存しない。バックエンドが、ファイルから計算する。
  - なぜ：保存すると、ファイルと値が食い違わないようにする仕組みが要るから。
- ファイルの変え方の決まりは、バックエンドが差分を検査して守る（[差分の検査](../backend/checks.md)）。
