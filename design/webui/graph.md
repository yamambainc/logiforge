# スナップショットツリーの図

ビュワーの図（ノードと線で描く表示）の描き方と置き方を実装するときに読む。
最初の表示、操作、フォーカス、キーボードは、[図の操作](graph-navigation.md) に書く。
アウトラインと共通の決まり（読み方、色と印）は、[スナップショットツリーのビュワー](snapshot-tree-viewer.md) に書く。検索と絞り込みは、[ビュワーの検索と絞り込み](viewer-search.md) に書く。

## ワイヤフレーム

```
+------------------------------------------------------------------+
|                    +----------------------+                      |
|                 ,--| ◆ 早く価値を体験…  [偽]|(-)--- …              |
| +-------------+ /   +----------------------+                     |
| | ○ 新しいオン |(-)  +----------------------+                     |
| |  ボーディング…|---- | ◆ つまずきを取り…[偽]|(+)                  |
| +-------------+ \   |  s-m1em    +88 ▬▬▬  |                      |
|                  `--| ◇ 呼び戻しが効く [未決]|(-)--- …              |
| [＋][－][全体][◎] 51%                                            |
+------------------------------------------------------------------+
```

## 描き方

- SVG で描く。レイアウトと、ズームとパンは、自前で書く。ライブラリは足さない。
  - なぜ SVG か：文字、押せる範囲、CSS の色を、アウトラインと同じ書き方で扱えるから。描くノードは、画面に入るものだけ（数十個）なので、Canvas にする速さは要らない。
  - なぜ自前か：レイアウトは約 40 行、ズームとパンは約 100 行で、描画を含めても約 350 行で書ける。d3 の `d3-zoom` は `d3-selection` などを連れてくるうえ、DOM を自分で書き換えるので、React が持つ SVG と取り合いになる（[フレームワーク](stack.md#フレームワーク)）。

## レイアウトと向き

- 向きは、横（左から右）と縦（上から下）の 2 つである。図の上の「横」「縦」で切り替える。URL の `orient` に持つ。
  - 既定は横である。デスクトップでもモバイルでも同じ。
  - なぜ横が既定か：主文は横に長いので、深さを横に並べると箱が重ならないから。また、縦は兄弟が横に並ぶので、幅の広い段で縮みやすいから（[最初の表示と収め直し](graph-navigation.md#最初の表示と収め直し)）。
  - 縦は、浅くて幅の広い部分木を、上から一目で見たいときに使う。モバイルでは、幅が狭いので、最初の表示で兄弟の一部しか入らない。
- 深さごとに列（横）か行（縦）を分ける。見えている葉に、順に 1 つずつ位置を割り当て、親は、最初の子と最後の子の真ん中に置く。
- ノードの箱の大きさは、次のとおりである。深さの間隔は、親子の間、葉の間隔は、隣の葉の間である。

| 向き | 端末 | 幅 | 高さ | 深さの間隔 | 葉の間隔 |
|---|---|---|---|---|---|
| 横 | デスクトップ | 264 px | 72 px | 324 px | 86 px |
| 横 | モバイル | 212 px | 70 px | 260 px | 82 px |
| 縦 | デスクトップ | 208 px | 72 px | 128 px | 224 px |
| 縦 | モバイル | 168 px | 70 px | 118 px | 182 px |

- 箱には、印、主文かタイトル（2 行まで）、値の札、識別子の先頭、札（[色と印](snapshot-tree-viewer.md#色と印)）を示す。
- 子のあるノードには、開閉のボタン（＋、－）を置く。横では箱の右、縦では箱の下である。閉じた部分木には、ノード数と、葉の値の内訳の横棒を示す。
- 向きを変えたら、[最初の表示](graph-navigation.md#最初の表示と収め直し) と同じ決まりで収め直す。

## 描く範囲

- 開いているノードだけを描く。開いているノードの集まりは、アウトラインと同じものを使う（[折りたたみ](snapshot-tree-viewer.md#折りたたみ)）。
  - なぜ：ノード 4,000 個をすべて描くと、線が重なって読めないから。
- そのうち、画面と、その周り 200 px に入るノードと線だけを描く。
- 縮小して 45% を下回ったら、文字を省き、形と色だけを描く。

## 検索、絞り込み、差分の重ね表示

- 示すノードは、アウトラインと同じである（[一致の示し方](viewer-search.md#一致の示し方)）。一致したノードは黄の枠、祖先は薄く示す。
- 差分の重ね表示の印は、アウトラインと同じ色を、箱の左端の線と背景に付ける（[差分の重ね表示](overlay.md#差分の重ね表示)）。
  - 消えるノードは、枠を点線にし、文字に取り消し線を引く。
  - 加わるノードへの線は緑、消えるノードへの線は赤の点線にする。
