# ビュワーの検索と絞り込み

ビュワーの検索と絞り込みを実装するときに読む。
表示の共通の決まりは、[スナップショットツリーのビュワー](snapshot-tree-viewer.md) に書く。検索と絞り込みは、3 つの表示で同じものを使う。

## 検索

- 検索は、主文、タイトル、識別子の部分一致である。大文字と小文字を区別しない。
- `Enter` で次の一致、`Shift+Enter` で前の一致を選ぶ。

## 絞り込み

- 絞り込みは、値（真、偽、未決）、未決の葉（作業）、要再検討、審査中の apply request、open の人への依頼である。
- 「未決の葉（作業）」と「要再検討（作業）」は、作業の定義と同じものを示す（[着手できる作業](../../docs/work/README.md)、`internal/backend/work.go`）。
  - inactive のもの、open の apply request が対象にしているもの、open の人への依頼があるものを除く。
  - ダッシュボードの件数と同じ数になる。
- 「要再検討（作業）」は、ダッシュボードから開いたとき（`f=nr-work`）だけ示す。ふだんの「要再検討」は、除かずにすべてを示す。
- 「引用元が変化（作業）」（`f=cited`）は、作業の一覧から対象の仮説を読んで示す。ダッシュボードから開いたときだけ示す。
- 選んだ絞り込みは、URL の `f`（`leaf,nr` のように並べる）に持つ。
  - なぜ：ダッシュボードの件数から、絞り込んだビュワーを開くため。
- 値どうしは「または」、ほかとは「かつ」で組み合わせる。検索とも「かつ」である。
- 「inactive を示す」を外すと、inactive なノードを隠す。inactive なノードの下も、まとめて隠す。
  - 切り替えは `localStorage` に置き、次に開いたときも同じにする。repository ごとには分けず、`/tree` と apply request の画面の木とで共通にする。
    - なぜ：inactive を見たいかは、見る人の好みで、開くたびに切り替えるのは手間だから。
  - 置いたものがないとき（初めて開いたとき）は隠す。この値は `webui/src/showInactive.ts` の 1 か所で決める。
  - 隠しているときに、隠れるノードを選んだ・表示の根にしたら（URL の `node` と `root`、apply request で変わるノード、詳細の子の一覧から選ぶ、など）、その場だけ示す。置いたものは変えないので、開き直すと元に戻る。
    - なぜ：開こうとしたノードが見えないと困るから。名指しで開くのは、隠すかどうかの好みを変えたいからではないから。
  - 隠しているあいだは、検索と絞り込みも、inactive なノードとその下に一致させない。
  - 隠れるノードを選んでいたとき・表示の根にしていたときに外したら、見えている、いちばん近い祖先に移す。

## 一致の示し方

- 一致したノードと、その祖先だけを示す。祖先は薄く示す。一致した語には印を付ける。
- 絞り込みのあいだは、3 つの表示のどれでも、開閉をさせない。
  - アウトラインと図では、開閉のボタンを示さない。
  - 3D では、「開く」「閉じる」を示さず、ダブルクリックも効かせない。
  - なぜ：一致したノードと祖先は、すべて開いて示すから。
