# ここから見る

ビュワーで、あるノードを表示の根にして、その下だけを示すところを実装するときに読む。表示の共通の決まりは、[スナップショットツリーのビュワー](snapshot-tree-viewer.md) に書く。

- 詳細のパネルの「ここから見る」で選ぶ。子のあるノードで、今の表示の根でないときに出す。
- 表示の根の上に、パンくずを出す。スナップショットツリーの根から表示の根までの祖先で、押すとそこを表示の根にする（上へ戻る）。「全体を見る」で、スナップショットツリーの根に戻る。
- 下へ進むには、子を選んで、また「ここから見る」を押す。
- 表示の根は、URL の `root` に持つ。変えたら、ブラウザの履歴に積む。
- 表示の根を変えたら、表示の根から 2 段を開き、表示の根を選ぶ。URL の `root` で開いたときと同じである。
- 検索と絞り込みの一致、前と次の変更は、表示の根の部分木の中だけで数える。
- 表示の根の外のノードを選んだら（詳細のパネルのパンくずなど）、スナップショットツリーの根から示す。これも履歴に積み、戻るで前の表示の根に戻れるようにする。URL の `node` が `root` の部分木の外のときも、スナップショットツリーの根から示す。
- 時点を変えても、表示の根がその時点にあれば、そのままにする。
- なぜ：ノードが数千あるスナップショットツリーでは、ある部分木だけを見たいことが多い。閉じるだけでは、祖先と兄弟の行が残り、図も広いままだから。
