# 着手できる作業とイベント

opener や reviewer が、次にする作業を見つけるときに読む。

- 作業の割り当てとループは、forge では行わない。
- forge が提供するのは、問い合わせと、イベントの読み出しの 2 つだけである。

## 着手できる作業

forge は、いま着手できる作業を返す問い合わせを提供する。
GitHub の `gh pr list --search review-requested` に相当する。

問い合わせは、次のものを返す。

- 未決の葉（[葉と検証結果](../tree/README.md)）
- 要再検討の仮説（[真偽値の伝播](../tree/propagation.md)）
- レビュー待ちの apply request
  - 最後の更新のあと、有効な `approve` も `request_changes` もない apply request をいう。
- 修正待ちの apply request
  - 最後のレビューが `request_changes` の apply request をいう。
  - 反映に失敗して `open` に戻った apply request も含める（[反映](../apply-request/README.md)）。
  - 修正待ちは、その apply request の opener の作業である。
- 回答済みの人への依頼（[人への依頼](../human-requests/README.md)）
  - 回答を検証結果に変えるのは、opener の作業である。
  - 次のどちらかが起きたら、作業から外す。
    - その回答の artifact を引用した apply request が、open になったか、反映された。
    - 回答のあとに、対象ノードについての apply request が反映された。
- 引用元が変化した検証結果（[検証結果と引用](../tree/verdict.md)）

問い合わせの範囲は、次のとおり。

- 返すのは、active なノードに関わる作業だけである。
  - なぜ：inactive な部分木は、伝播に関与しないから（[inactive 化](../tree/inactive.md)）。
- 木のノードについての作業（未決の葉、要再検討の仮説、引用元が変化した検証結果）は、そのノードを対象にした open の apply request があれば、既定では返さない。
  - なぜ：同じ作業に、複数の主体が同時に手を付けないようにするため。
- open の人への依頼がある葉と仮説は、着手できる作業に含めない。
  - なぜ：人の回答を待っているノードだから。
- 部分木を指定して、その中の作業だけを問い合わせられる。

## 作業の終わりの判定

forge は、1 つの木の作業が終わったかどうかを判定する、専用の問い合わせを提供する。
この問い合わせは、根拠部分木を対象にして、次の 2 つを確かめる。

- 根の値が決まっている。
  - 根の値が決まるとは、true か false になることをいう。
- 根拠部分木で、着手できる作業が 0 件である。
  - 根拠部分木は、[真偽値の伝播](../tree/propagation.md) に定義がある。
  - 根拠部分木のノードを対象にした、レビュー待ちと修正待ちの apply request も、数に含める。
  - なぜ：引用元が変化しても値は自動では変えないので、根拠部分木の見直しを終えるまでは結論を確定できないから。

## イベント

外の仕組みは、問い合わせとイベントの読み出しで、forge の変化を知る。

- forge は、着手できる作業が変わりうる変化を、repository ごとのイベントとして記録する。
- 外の仕組みは、前に読んだ位置より後のイベントを、定期的に読む。
- イベントには、変化した対象の種類と識別子だけを入れる。
  - なぜ：イベントは、着手できる作業を問い合わせ直すきっかけだから。
- 未決の葉や要再検討の仮説は、apply request が反映されたときに生まれる。

forge から外の仕組みへ、変化を送ることはしない。

- なぜ：送り直しや配信の状態を forge が持たずに済み、単純になるから。

## ループ

- 作業のループは、既存の仕組みで回す。
  - 例：Claude Code の /loop、cron、GitHub Actions の schedule
- それらの仕組みの使い方は、この仕様には書かない。

## 対応しないこと

- 作業を特定の主体に割り当てること
- 作業の担当を付け替えること
- 作業の優先度を決めること
