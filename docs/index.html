Logiforge 概要

clone した手元で開き、Logiforge の全体を数分でつかむための概要ページ。

仕様の正本は md にある。詳しい決まりは、各リンク先の md を読む。

目的

研究のように答えの分からない問いを、「仮説」と「ストーリー」の木に分けて管理する。

仮説と根拠を記録する正本（system of record）であり、git のホスティングサービス（GitForge）がコードの正本であるのと同じ位置づけである。

どの結論がどの根拠に基づくかを、あとから辿れるようにする。→ 目的と範囲

3 分でわかる要点

  1. 究極の問いを根にして、仮説とストーリーが交互に並ぶ木を作る。→ 仮説とストーリーの木
  2. 値を入れるのは、葉の仮説の検証結果だけ。上位の値は、すべて自動で計算する。→ 真偽値の伝播
  3. 木への変更は、すべて apply request を通す。差分を書いたのとは別のセッションの reviewer が承認する。→ apply request
  4. 偽が出ても、親の仮説は自動では棄却しない。別のストーリーを探す。→ 仮説が偽になったとき
  5. 作業は「着手できる作業」の問い合わせで見つけ、ループは外の仕組みで回す。→ 着手できる作業
