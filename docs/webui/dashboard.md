# ダッシュボード

利用者が、作業の状況をつかむときに使う画面。

## ワイヤフレーム

```
+---------------------------------------------------------------+
| 根: H0 究極の問い             値: [null]                       |
+---------------------------------------------------------------+
| 作業の終わりの判定                                             |
|  根の値が決まっている                  いいえ                  |
|  根拠部分木で着手できる作業            -                       |
+---------------------------------------------------------------+
| 着手できる作業                                                 |
|  未決の葉 5   要再検討 1   レビュー待ち 2   返信待ち 1         |
|  引用元が変化した検証結果 0                                    |
+---------------------------------------------------------------+
```

## 表示するもの

- 根の値
- [作業の終わりの判定](../work/README.md) の各条件を、満たしているかどうか
- [着手できる作業](../work/README.md) の件数（種類ごと）
