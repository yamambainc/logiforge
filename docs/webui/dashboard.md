# ダッシュボード

利用者が、作業の状況をつかむときに使う画面。

## ワイヤフレーム

```
+---------------------------------------------------------------+
| 根: H0 究極の問い             値: [null]                       |
+---------------------------------------------------------------+
|  作業の終わり      まだ：根の値が決まっていない                |
+---------------------------------------------------------------+
| 着手できる作業                                                 |
|  未決の葉 5   要再検討 1   レビュー待ち 2   回答済みの依頼 1   |
|  引用元が変化した検証結果 0                                    |
+---------------------------------------------------------------+
```

## 表示するもの

- 根の値
- [作業の終わり](../work/README.md) を 1 行で示す。「終わった」か、「まだ：着手できる作業 N 件」か、「まだ：根の値が決まっていない」
- [着手できる作業](../work/README.md) の件数（種類ごと）
  - 件数を押すと、その種類の作業の一覧へ行く。一覧に出る数は、件数と同じである。
- 根拠部分木で着手できる作業の件数は、根の値が決まってから数える。
