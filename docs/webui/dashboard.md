# ダッシュボード

利用者が、ループの状況をつかみ、必要なら止めるときに使う画面。

## ワイヤフレーム

```
+---------------------------------------------------------------+
| 根: H0 究極の問い             値: [null]                       |
+---------------------------------------------------------------+
| 停止条件                                                       |
|  根の値が決まっている        いいえ                            |
|  根拠部分木の未処理タスク    -                                 |
|  予算の消化                  ████████░░  80%                   |
+---------------------------------------------------------------+
| 開いているタスク  12   開いているスレッド  3   要再検討  1     |
+---------------------------------------------------------------+
|                                        [一時停止] / [再開]     |
+---------------------------------------------------------------+
```

## 表示するもの

- 根の値
- [停止条件](../agents/scheduler.md) のそれぞれを、満たしているかどうか
- 予算の消化の度合い
- 開いているタスクの数
- 開いているスレッドの数
- 要再検討の仮説の数

## 一時停止

- 利用者は、ループを一時停止できる。
- 利用者は、一時停止したループを再開できる。
- 一時停止の間、スケジューラはタスクを割り当てない。
