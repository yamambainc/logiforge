# 木のビューア

利用者が、木の全体と、各ノードの根拠を見るときに使う画面。

## ワイヤフレーム

```
+----------------------------------------------------------------+
| [根の主文を作る]                         検索 [__________]     |
+------------------------------+---------------------------------+
| ▼ H0 究極の問い     [true]   | H3  ある仮説の主文              |
|   ▼ S1 ストーリー1  [false]  | 値: true                         |
|       H1 ...        [true]   | 背景情報: ...                    |
|       H2 ...        [false]  | 検証結果のレポート: ...          |
|   ▼ S2 ストーリー2  [true]   | artifact: run.py / run.log       |
|       H3 ...        [true] ◀ | 引用: H1 の部分木（リビジョン）  |
|     ▶ H4 ...        [true]   | 履歴: ...                        |
|   ▶ S0 旧ストーリー (灰色)   | [スレッドを開く]                 |
+------------------------------+---------------------------------+
```

## 木の表示

- 木は、折りたためる形で表示する。
- 値は、色で示す（true、false、null）。
- inactive な部分木は、灰色で示す。
- 次のものを、バッジで示す。
  - 要再検討（[真偽値の伝播](../tree/propagation.md)）
  - 審査中の apply request
  - 開いているスレッド

## ノードの詳細

選んだノードについて、次のものを示す。

- 仮説の主文と背景情報
- ストーリーのタイトルと概要
- 検証結果と、そのレポート
- artifact
- 引用しているもの
- 引用されているもの
- そのノードの履歴

## 根の主文の作成

- 木がまだないとき、利用者は根の主文を書いて木を作る。
- 主文の文字数は、[仮説](../tree/README.md) の決まりに従う。
