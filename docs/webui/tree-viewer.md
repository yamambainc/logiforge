# 木のビューア

利用者が、木の全体と、各ノードの根拠を見るときに使う画面。

## ワイヤフレーム

```
+----------------------------------------------------------------+
| repository: [question-a ▼]               検索 [__________]     |
+------------------------------+---------------------------------+
| ▼ H0 究極の問い     [true]   | H3  ある仮説の主文              |
|   ▼ S1 ストーリー1  [false]  | 値: true                         |
|       H1 ...        [true]   | 背景情報: ...                    |
|       H2 ...        [false]  | 検証結果のレポート: ...          |
|   ▼ S2 ストーリー2  [true]   | artifact: run.py / run.log       |
|       H3 ...        [true] ◀ | 引用: H1 の部分木                |
|     ▶ H4 ...        [true]   | 履歴: ...                        |
|   ▶ S0 旧ストーリー (灰色)   | 人への依頼: PVR（open）          |
+------------------------------+---------------------------------+
```

## 木の表示

- 木は、次の 3 つの表示で示し、切り替えられる。選んだノードと、開いたノードは、3 つの表示で同じにする。
  - 字下げした一覧（アウトライン）
  - ノードと線の図。ズームとパンができ、ノードを押すと開閉と詳細ができる。向きは、横（左から右）と縦（上から下）を切り替えられる
  - 3D の表示。マウスでも指でも、回す・ズーム・パンができ、ノードを押すと開閉と詳細ができる
- 値の色、検索、絞り込み、apply request を反映したあとの姿は、3 つの表示のどれにも示す。
- 木は、折りたためる形で表示する。
- 最新のコミットが valid でなければ、いちばん新しい valid なコミットの木を示し、画面の上に「最新のコミットは valid でない。コミット X の木を示している」と示す（[main への直接の変更](../apply-request/README.md#main-への直接の変更)）。
- 値は、色で示す（true、false、null）。
- inactive な部分木は、灰色で示す。はじめは隠していて、絞り込みの「inactive」で示せる。切り替えはブラウザに覚えさせ、次に開いたときも同じにする。
- 隠しているときに inactive なノードを名指しで開くと（リンクや apply request から）、その場だけ示す。
- 次のものを、バッジで示す。
  - 要再検討（[真偽値の伝播](../tree/propagation.md)）
  - 審査中の apply request
  - open の人への依頼

## 過去の時点の木

- 上の「時点」で `main` のコミットを選ぶと、その時点の木を示す。
  - 選択肢は、新しい順に 50 個ずつ示す。「さらに古いコミット…」で、続きを読む。
- 過去の時点では、審査中の apply request と open の人への依頼の札を示さない。これらは今のものだからである。
- 上の帯に、コミットの番号と時刻を示し、今の `main` に戻るボタンを置く。

## ノードの詳細

選んだノードについて、次のものを示す。

- 仮説の主文と背景情報
- ストーリーのタイトルと概要
- 検証結果と、そのレポート
- artifact
- 引用しているもの
- 引用されているもの
- そのノードの履歴
- 審査中の apply request
- open の人への依頼
