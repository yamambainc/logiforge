# AR と履歴の画面

owner が、木がどう変わってきたかを確かめるときに使う画面。
AR の決まりは、[Apply Request](../apply-request/README.md) に書く。

## ワイヤフレーム

```
+---------------------------------------------------------------+
| AR と履歴    状態: [open ▼]       時点: [最新 ▼]              |
+-------------------------+-------------------------------------+
| AR  S2 の作成  open     | 差分                                |
| AR  H2 の検証  merged   |  + story.create  S2 ストーリー2      |
| AR  S0 の外し  merged   |  + verdict.submit H3 true            |
|                         | レビュー                            |
|                         |  Reviewer: request_changes  ...     |
|                         |  Builder:  修正しました ...          |
+-------------------------+-------------------------------------+
```

## AR の閲覧

- AR を、状態（open、merged、closed）で絞り込める。
- 選んだ AR の差分と、レビューと、コメントを示す。
- WebUI からは、AR を審査しない。
  - なぜ：審査は Reviewer の役割だから（[役割](../agents/README.md)）。

## 過去の時点の木

- 時点を選ぶと、その時点の木を [木のビューア](tree-viewer.md) と同じ形で示す。
