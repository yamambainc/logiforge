# 人への依頼の画面

利用者が、人への依頼を見つけて回答するときに使う画面。
人への依頼の決まりは、[人への依頼](../human-requests/README.md) に書く。

## ワイヤフレーム

```
+---------------------------------------------------------------+
| 人への依頼   種類: [PVR ▼]     状態: [open ▼]                  |
+-------------------------+-------------------------------------+
| ● PVR  H7 の検証手順    | PVR  H7 の検証手順                  |
|   判断  H3 の進め方     | 対象: H7  ある仮説の主文            |
|                         | 手順:                               |
|                         |   1. ...                            |
|                         |   2. ...                            |
|                         | ---------------------------------   |
|                         | [回答を書く ___________________]    |
|                         | [ファイルを添付]  [回答する]        |
+-------------------------+-------------------------------------+
```

## 一覧

- 人への依頼を、種類（PVR、判断）で絞り込める。
- 人への依頼を、状態（open、answered）で絞り込める。

## 回答

- 利用者は、本文（検証手順、または問い）を読み、回答を自由記述で書く。
- ファイルや写真を添付できる。大きなものは、リンクを添える（[artifact](../tree/verdict.md)）。
- 回答は 1 回だけで、回答したあとは変えられない（[人への依頼](../human-requests/README.md)）。
