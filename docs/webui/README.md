# WebUI

人間がハーネスを使う画面の決まりを確かめるときに読む。
WebUI を使うのは owner である。owner ができることは、[役割](../agents/README.md) に書く。

## 画面

- [木のビューア](tree-viewer.md)：木と、各ノードの詳細を見る。
- [スレッド](threads.md)：依頼を出し、PVR に結果を記入する。
- [AR と履歴](history.md)：AR の差分と議論を見る。過去の時点の木を見る。
- [ダッシュボード](dashboard.md)：ループの状況を見て、一時停止する。

## 共通の決まり

- 木の変更（ストーリーの作成、検証結果の提出など）は、WebUI からは行わない。
  - なぜ：owner の操作は、根の主文の作成、スレッドへの記入、一時停止の 3 つだけだから。
- 根の主文は、[木のビューア](tree-viewer.md) から作る。
