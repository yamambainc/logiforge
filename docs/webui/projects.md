# project の一覧

利用者が、扱う project を選ぶときと、新しい問いを持ち込むときに使う画面。
project の決まりは、[仮説とストーリーの木](../tree/README.md) に書く。

## ワイヤフレーム

```
+---------------------------------------------------------------+
| project                                 [新しい project] |
+---------------------------------------------------------------+
| question-a        根: ある究極の問いの主文         値: [null]  |
| question-b        根: 別の問いの主文               値: [true]  |
+---------------------------------------------------------------+
```

## 一覧と選択

- project を、根の主文と根の値と一緒に一覧する。
- project を選ぶと、ほかの画面はその project を表示する。

## project の作成

- 利用者は、project の名前と、根の仮説の主文を書いて、project を作る。
- 主文の文字数は、[仮説](../tree/README.md) の決まりに従う。
