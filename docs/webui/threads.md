# スレッドの画面

利用者が、エージェントに依頼を出すときと、PVR に結果を記入するときに使う画面。
スレッドの決まりは、[スレッド](../threads/README.md) に書く。

## ワイヤフレーム

```
+---------------------------------------------------------------+
| スレッド   [依頼] [PVR]        状態: [open ▼]   [新しい依頼]  |
+-------------------------+-------------------------------------+
| ● PVR  H7 の検証手順    | PVR  H7 の検証手順                  |
|   依頼  ...             | 対象: H7  ある仮説の主文            |
|   依頼  ...             | 手順:                               |
|                         |   1. ...                            |
|                         |   2. ...                            |
|                         | ---------------------------------   |
|                         | Builder: ...                        |
|                         | 利用者: ...                         |
|                         | [結果を書く ___________________]    |
|                         | [ファイルを添付]  [送信]            |
+-------------------------+-------------------------------------+
```

## 一覧

- スレッドを、種類（依頼、PVR）で絞り込める。
- スレッドを、状態（open、closed）で絞り込める。

## 依頼の作成

- 利用者は、本文を自由記述で書く。
- 対象のノードは、指定してもしなくてもよい。

## PVR への記入

- 利用者は、検証手順を読み、結果を自由記述で書く。
- ファイルや写真を添付できる。
- 記入の扱いは、[PVR](../threads/README.md) に書く。
