# セットアップ

Logiforge を初めて起動したときに、GitForge とのつなぎ方と最初の利用者を決める画面。
セットアップが終わるまで、WebUI はこの画面だけを示す。

- セットアップが終わるまでは、だれでもこの画面を使える（[だれがセットアップできるか](../../design/settings/setup.md#だれがセットアップできるか)）。
- セットアップが終わったら、この画面は使えなくなる。

## ワイヤフレーム

```
+---------------------------------------------------------------+
| Logiforge のセットアップ                                      |
+---------------------------------------------------------------+
| 1. 構成        (o) GitHub   ( ) Forgejo                       |
| 2. GitHub App  owner [ my-org        ]  WebUI [ https://... ] |
|                [x] ほかの owner にも install する              |
|                [GitHub で App を作る]                          |
| 3. install     [GitHub で install する]                        |
| 4. repository  名前 [ question-a ]  owner/name [ my-org/q-a ] |
| 5. サインイン  [GitHub でサインインして、利用者になる]         |
+---------------------------------------------------------------+
```

Forgejo を選んだときは、2 から 5 のかわりに、次の段を示す。

```
+---------------------------------------------------------------+
| 2. Forgejo     URL [ https://forgejo.example ]                |
|                ブラウザからの URL [                ]          |
|                organization [ my-org ]                        |
|                redirect_uri: https://.../oauth/callback       |
|                client_id [      ]  client secret [      ]     |
|                worker  [ user ]  トークン [      ]  [確かめる]|
| 3. サインイン  [Forgejo でサインインして、利用者になる]        |
+---------------------------------------------------------------+
```

## 段

- 段は、上から順に進める。前の段が終わるまで、次の段は押せない。
- 途中でページを閉じても、入れた設定は残る。同じブラウザで開き直せば、続きから進む。
- 続けられるのは、セットアップを始めたブラウザだけである。ほかのブラウザで開くと、「セットアップは別のブラウザで進行中です。最初からやり直すときは、設定の DB を消して起動し直してください」と示す。
  - なぜ：途中で、ほかの人に GitHub App や Forgejo のつなぎ方を差し替えられないようにするため（[初回のセットアップ](../../design/settings/setup.md#だれがセットアップできるか)）。
- 最後の段でサインインした人が、最初の利用者になる。
  - GitHub を選んだときは、4 の repository に書ける人でなければならない。
  - Forgejo を選んだときは、organization の team で、コードを書ける人でなければならない。
  - 終わったら、[設定の画面](settings.md#repository-を足す) を開く。
    - GitHub を選んだときは、4 の repository の最初の問いを入れる段を開く。スナップショットツリーがもうあれば、足す段の 1 から開く。
    - Forgejo を選んだときは、足す段の 1 から開く。

## 秘密の扱い

- client secret とトークンの入力欄は、入力の文字を隠す。
- 置いた秘密は、画面に戻さない。「置きました」とだけ示す。
