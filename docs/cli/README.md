# CLI

エージェントがハーネスを使うときの、CLI の決まりを確かめるときに読む。

## 形

- gh に似た CLI を用意する。
  - なぜ：エージェントは gh のような CLI を使い慣れているから。
- すべてのコマンドに `--json` を付けられる。
  - なぜ：エージェントが出力を機械的に読めるようにするため。
- 木を変えるコマンドは、どれも [Apply Request](../apply-request/README.md) を作るか、既存の AR に操作を加える。
  - 対象のコマンド：ストーリーの作成、ストーリーの inactive 化、検証結果の提出、背景情報への追加。
  - なぜ：正式なデータを変えられるのは、承認された AR の適用だけだから（[変更の経路](../tree/README.md)）。

## 常駐ループ

- エージェントは、計算機の中の特定のディレクトリに常駐する。
- エージェントは、タスクを受け取って処理することを繰り返す。
  - タスクは、[スケジューラ](../agents/scheduler.md) から受け取る。

```bash
while true; do
  task=$(hv task next --role builder --wait --json)
  # task の種類に応じて、ストーリーの作成や検証結果の提出などを行う
  hv task done "$(jq -r .id <<<"$task")"
done
```

`hv` は、CLI の仮の名前である。

## 対応しないこと

- 人間向けの操作は、CLI では提供しない。人間は [WebUI](../webui/README.md) を使う。
