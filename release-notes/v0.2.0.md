## 互換のない変更

v0.2.0 は、v0.1.0 と互換がない。v0.1.0 で作った repository は、v0.2.0 では使えないので、作り直す。

- 記録の署名を、HMAC から Ed25519 に変えた。v0.1.0 が書いた記録（apply request、レビュー、回答）は、署名が合わないので数えない。
- Logiforge の書き込み主体（`LOGIFORGE_WRITER`、`LOGIFORGE_WRITER_TOKEN`）をなくした。GitForge には、要求を送った主体のトークンで書く。反映は、`approve` をした reviewer のトークンで merge する。
- worker に、記録の署名の公開鍵（`LOGIFORGE_RECORD_PUBLIC_KEYS`）が要る。`logiforge record-public-keys` で作る。
- 用意のコミット（根のコミット）に、署名（`Logiforge-Init-Signature:`）を求める。v0.1.0 で作った repository の根には署名がないので、worker が取り込まない。

### 作り直し方

1. v0.2.0 に上げる前に、v0.1.0 のまま、repository の open の apply request と人への依頼を片付ける。
2. 結論を残したいときは、v0.2.0 に上げる前に、v0.1.0 のまま、スナップショットツリーを書き出しておく（`logiforge tree export --format json > <repository の名前>.json`）。
   - なぜ上げる前か：v0.2.0 の worker は、署名のない根の repository を取り込まないので、上げたあとでは書き出せないから。
3. v0.2.0 に上げ、新しい名前で repository を作る（WebUI か API）。書き出したものは、新しい repository に apply request で書き直す。
4. v0.1.0 の repository は、GitForge で archive にする。
