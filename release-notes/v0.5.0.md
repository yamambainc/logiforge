## 新しいこと

- GitHub を使う構成では、CLI は、トークンがなければ `gh auth token` を読む（[gh のトークン](https://github.com/yamambainc/logiforge/blob/v0.5.0/design/cli/auth.md#gh-のトークン)）。
  - `gh auth login` のあとは、`logiforge auth login --host <URL>` でバックエンドの URL を置くだけでよい。`gh auth token | logiforge auth login --with-token` は要らない。
  - git の credential helper（`logiforge auth git-credential`）も同じなので、push も `gh auth login` だけでできる。
  - gh のトークンが変わっても、置き直さなくてよい。
  - `LOGIFORGE_TOKEN` と設定ファイルのトークンは、これまでどおり gh より先に使う。
- Forgejo を使う構成の CLI の動きは、変わらない。gh を呼ばない。
