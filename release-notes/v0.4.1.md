## 新しいこと

- GitHub を使う構成では、CLI は、トークンがなければ `gh auth token` を読む（[gh のトークン](https://github.com/yamambainc/logiforge/blob/v0.4.1/design/cli/auth.md#gh-のトークン)）。
  - `gh auth login` のあとは、`logiforge auth login --host <URL>` でバックエンドの URL を置くだけでよい。`gh auth token | logiforge auth login --with-token` は要らない。
  - git の credential helper（`logiforge auth git-credential`）も同じなので、push も `gh auth login` だけでできる。
  - gh のトークンが変わっても、置き直さなくてよい。
  - `LOGIFORGE_TOKEN` と設定ファイルのトークンは、これまでどおり gh より先に使う。
  - gh を使うのは、バックエンドの URL が https のときだけである。
- Forgejo を使う構成の CLI は、gh を呼ばない。トークンがないときは、`getOAuthConfig` を 1 回呼んで構成を確かめてから、これまでと同じ誤りにする（待つのは 3 秒まで）。
- トークンがないときの誤りの文言を、`--token` ではなく `--with-token` を勧めるように変えた。
